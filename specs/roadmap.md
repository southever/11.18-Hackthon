# 脉络 · 一小时 Demo 路线图

目标是在一台电脑上走通自动记录、跨会话记忆、关系画布和 spec 导出，再用同一份真实记录做浏览器全屏路演。时间从开始实现时计算。

| 时间 | 阶段 | 通过条件 |
| --- | --- | --- |
| 0–10 分钟 | 打通一轮采集 | 在 IDE 终端正常和 Codex 对话，本地数据库出现这轮用户要求、可见回复及可获取的工具结果。此时开始录制演示项目。 |
| 10–22 分钟 | 让想法跨会话接续 | 同一项目的第二个会话改变要求，整理器自动连出一个“取代”和一个“沿用”关系。重开项目仍可点回对应来源。 |
| 22–36 分钟 | 把记忆画进侧栏 | 窄栏可看当前想法和相关卡片，点开旧分支可读原话或操作结果。新增一轮后，用户能看到哪些关系发生了变化。 |
| 36–46 分钟 | 生成当前 spec | 从侧栏导出可独立阅读的 Markdown，内容涵盖当前目标、已定方向、重要取舍和待定事项。旧方案在取舍中出现，当前要求与画布一致。 |
| 46–55 分钟 | 做本地全屏回放 | 从真实记录生成回放包。浏览器能前进、后退、暂停，停在哪一步就显示当时的想法、关系、网站预览和 spec。 |
| 55–60 分钟 | 安装与彩排 | 安装 VSIX，重新打开演示项目，验证历史仍在；断网打开本机回放，完成下面的 90 秒展示。 |

## 90 秒路演脚本

| 时间 | 现场展示 |
| --- | --- |
| 0–20 秒 | 打开真实会话回放。用户请 AI 做校园电影节网站，先用海报轮播放首页。画布出现第一个方案，点开可看当时做出的首页。 |
| 20–55 秒 | 下一次会话里，用户看到预览后提出“同学扫码进来，先想知道今晚几点开场。首页改成场次表，海报放到详情页。”画布展开两条关系：场次表取代首页轮播，详情页沿用原来的海报。 |
| 55–75 秒 | 暂停，点开“首页轮播”看最初的要求，再点开新首页的预览。观众可以对照用户说了什么、AI 实际改了什么，以及哪些内容被保留。 |
| 75–90 秒 | 打开最后一步的 spec，展示一段可直接交给下一轮 AI 的项目说明。回到 IDE 侧栏，显示同一个项目和同一组决定。 |

电影节是预定的录制题材。录制时保留实际措辞、操作及对应版本的预览，回放以采集结果为准。若制作时间紧，优先缩减动画和预览装饰，保住真实采集、可追溯的分支和当前 spec。
