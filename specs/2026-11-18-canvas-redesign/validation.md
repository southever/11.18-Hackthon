# 验收

- [x] 在 1440 × 900 和 1280 × 800 的浏览器中打开校园电影节的两轮真实回放。默认画布包含当轮决定和相邻想法，可直接点选“取代”和“沿用”。[桌面截图](../../docs/canvas.png)
- [x] 点选卡片或关系可查看来源，关闭后可继续回放。两轮的作品截图和 HTML 预览均能打开，各轮导出的 Markdown 与所选快照逐字一致。
- [x] 在 850 × 720、390 × 780 和实际 VS Code 的 300 像素侧栏中检查。390 像素宽时纵向卡片宽 348 像素，侧栏可展开关系、切换历史、打开网站预览及导出 Markdown。桌面完整画布支持缩放和复位。
- [x] 5 项自动化测试通过。解压路演包运行 `node scripts/demo.mjs`，首页、脚本、样式、两轮回放和对应作品预览均返回 HTTP 200。VSIX 安装到独立 VS Code 配置后，侧栏可切换到磁盘上的另一份真实项目记录。VSIX 和 ZIP 中的前端文件与此次构建逐字节一致。
