# 画布阅读体验

Pace your thought with agents 的首屏应让人沿着线读懂想法如何变化。浏览器和 VS Code 侧栏共用画布，以纸面浅色、墨色文字和鼠尾草绿为默认配色。标题、卡片、关系词和留白构成层次，状态同时用文字说明。

- 当前决定、被替代的想法与沿用的内容在默认视图可见。连线有方向，关键关系词避开卡片，长标题有详情可读。
- 浏览器以画布为主，保留会话切换、作品预览和回放。点选卡片或连线展开来源，关闭后回到当前轮次。窄侧栏默认将当前决定与相邻分支纵向排列，可切换到“全部想法”查看完整关系图。
- 使用新项目名。保留现有快照格式、Markdown 导出、宿主消息及本地离线工作方式。

借鉴 [React Flow 的自定义边](https://reactflow.dev/examples/edges/custom-edges) 将线形与文字交互分开；借鉴 [tldraw 的自定义工具栏](https://tldraw.dev/examples/custom-ui) 按画布任务选择控件。
