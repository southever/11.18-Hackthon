# 脉络 MindTrace

脉络把一个人和 AI 一起做事的过程画成一张想法关系图。你照常在 VS Code 的终端里和 Codex 对话，侧栏会记下提出的想法、实际的尝试和后来改变的决定。同一个项目换个会话，仍能接着看。

## 在本机打开路演

安装 Node.js 24。下载并解压发行包 `mailuo-roadshow.zip`，在解压后的目录运行：

```sh
node scripts/demo.mjs --open
```

浏览器默认展示项目最新的画布。点击播放可从第一轮重看，按 F11 进入全屏。演示使用包内的真实会话记录和当时的网站作品，播放时可断网。

路演中的节点与关系根据实际录下的对话和工具记录整理，点开即可查看依据。第二轮已写入新版网站，Codex 在发出轮末回复前达到账号用量上限，因此该轮保留至最后一条工具记录。

从本仓库启动开发版：

```sh
npm run setup
npm run build
npm run demo -- --open
```

## 用自己的项目

1. 在 VS Code 的扩展视图选择「从 VSIX 安装」，打开 `mailuo-0.1.0.vsix`。
2. 打开项目文件夹，从活动栏进入「脉络」，运行「启用项目记录」。在该项目启动 Codex CLI，通过 `/hooks` 审阅并启用脉络的项目 hooks。
3. 继续在原终端与 Codex 对话。点开画布卡片或关系线可查看来源，在项目说明中可将当前 spec 导出为 Markdown。
4. 想先看例子时，从命令面板运行「在侧栏查看路演示例」；「在侧栏查看当前工作区」切回自己的项目。

采集和整理使用本机的 Node.js 24 及已登录的 Codex CLI。Windows 下项目数据库默认在 `%LOCALAPPDATA%/Mailuo`，可用 `MAILUO_DATA_DIR` 指定目录。语义整理调用当前 Codex 账户可用的模型，回放直接读取本地快照。

## 90 秒怎么讲

- **看想法从哪里来。** 打开电影节网站的第一版，用户原本想把海报轮播放在首页。点卡片可读到这条原话。
- **看方向怎样改变。** 用户发现扫码的同学更关心几点开场。播放下一轮，看场次表取代首页轮播，原海报留在影片详情里。
- **看能带走什么。** 打开当时的网站预览，再查看项目说明。画布保留过程，导出的 Markdown 交代当前要做什么，以及哪些想法被沿用。

项目章程见 [产品定位](specs/mission.md)、[技术选型](specs/tech-stack.md) 和 [分阶段路线图](specs/roadmap.md)。运行 `npm test` 检查实现，运行 `npm run package` 重新生成 VSIX。
