# Pace your thought with agents

在 VS Code 侧栏查看 Codex 对话积累的项目记忆，浏览想法关系和依据，并导出当前项目说明。

1. 安装 Node.js 24 和 Codex CLI。登录 Codex 后，在 VS Code 打开本地项目。
2. 点击活动栏的扩展图标，在侧栏选择「启用项目记录」。
3. 在项目终端启动 Codex，输入 `/hooks`，审阅并信任扩展的三项项目 hooks。
4. 照常与 Codex 对话。侧栏会更新该工作区的想法、关系和来源。

命令面板中的「Pace your thought with agents: 打开内置演示回放」可在浏览器离线播放随包附带的电影节案例。

在命令面板选择「在侧栏查看路演示例」可浏览同一案例，选择「在侧栏查看当前工作区」可切回当前项目。
